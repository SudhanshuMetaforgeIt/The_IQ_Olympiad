# The IQ Olympiad

A comprehensive digital Olympiad platform for students, schools, and administrators.

## Architecture

- Frontend: Next.js
- Backend: NestJS
- Database: MongoDB
- ODM: Mongoose
- AI Engine: Python + FastAPI
- AI Orchestration: LangGraph
- Vector Database: Qdrant
- Cache & Queues: Redis
- 3D Experience: Three.js + React Three Fiber
- Monorepo: Turborepo + pnpm
